# Section 301 List 1 thesis code

This repository contains cleaned code files used for the master thesis on U.S. Section 301 List 1 tariffs and U.S. import dependence on China.

## Contents

- `code/01_dataweb_extraction_logic.py`: Sanitised Python code showing the USITC DataWeb extraction logic, batching procedure, response cleaning, and extraction-summary construction.
- `code/02_regression_implementation.R`: R code for the baseline difference-in-differences, event-study, heterogeneity, and robustness specifications.
- `code/03_figure_generation.R`: R code used to generate the main and appendix figures.

## Notes

Authentication details, API access tokens, raw API headers, and exploratory notebook outputs are excluded. The code is provided for transparency and should be read together with the data-construction and variable definitions reported in the thesis appendix.
